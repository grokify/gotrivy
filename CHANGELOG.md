## [v0.5.0] - 2026-10-05 ([`069e279`](https://github.com/grokify/gotrivy/commit/069e279))

### Highlights

- Trivy reports now convert to the shared [findingspec](https://github.com/plexusone/findingspec) IR — normalized findings usable across scanners
- New `ScanFilepath` wrapper and `cmd/gotrivyscan` CLI run `trivy fs` and return a parsed report

### Added

- Trivy report → `findingspec.Finding` conversion (security domain) with typed CVSS, fix state, and package metadata ([`069e279`](https://github.com/grokify/gotrivy/commit/069e279))
- `ScanFilepath` runs `trivy fs --format json --scanners vuln` via the installed trivy binary and returns the parsed `types.Report` ([`2fb760b`](https://github.com/grokify/gotrivy/commit/2fb760b))
- `cmd/gotrivyscan` CLI: scan a path and write an XLSX report ([`2fb760b`](https://github.com/grokify/gotrivy/commit/2fb760b))

### Fixed

- Restore a consistent `go.sum` after a dependency-update merge left entries missing ([`654cfaf`](https://github.com/grokify/gotrivy/commit/654cfaf))
